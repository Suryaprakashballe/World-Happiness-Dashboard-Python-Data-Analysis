# 🌍 World Happiness Analysis & Prediction

**Python Data Analysis & Introductory Machine Learning Project**

---

## 📌 Business Problem

Understanding what drives happiness across countries is essential for policymakers, organizations, and researchers. While economic indicators such as GDP are important, non-economic factors like social support and health also play a critical role.

This project analyzes global happiness data to identify **key factors influencing happiness** and builds a **basic predictive model** to estimate happiness scores.

---

## 🎯 Objectives

* Analyze global happiness trends across countries
* Identify key factors influencing happiness scores
* Compare regional variations in well-being
* Build a simple machine learning model to predict happiness
* Derive insights for policy and decision-making

---

## 📂 Dataset

* **Source:** World Happiness Report (public dataset)
* **Coverage:** Multiple countries across years

### Key Features:

* Happiness Score
* GDP per Capita
* Healthy Life Expectancy
* Social Support
* Freedom to Make Life Choices
* Perceptions of Corruption
* Region

---

## 🛠 Tools & Technologies

* **Python:** Pandas, NumPy
* **Visualization:** Matplotlib, Seaborn, Plotly
* **Machine Learning:** Linear Regression
* **Environment:** Jupyter Notebook
* **Version Control:** Git & GitHub

---

## 🔍 Methodology

1. Data loading and preprocessing
2. Handling missing values and cleaning dataset
3. Exploratory Data Analysis (EDA)
4. Correlation analysis between variables
5. Feature selection for modeling
6. Built a **Linear Regression model** to predict happiness score
7. Evaluated model performance

---

## 📊 Key Analysis

* Distribution of happiness scores across countries
* Correlation between GDP and happiness
* Impact of social support and health on well-being
* Regional comparison of happiness levels
* Identification of top and lowest-ranking countries

---

## 📈 Key Insights

* GDP per capita positively influences happiness, but is **not the sole determinant**
* Social support is one of the **strongest predictors of happiness**
* Healthy life expectancy significantly contributes to higher well-being
* Regional disparities highlight differences in economic and social conditions
* Some countries outperform expectations due to strong social structures

---

## 🤖 Machine Learning Model

* Model Used: **Linear Regression**
* Goal: Predict happiness score based on key features
* Evaluation Metrics:

  * R² Score
  * Mean Absolute Error (MAE)

👉 The model demonstrates how multiple socio-economic factors collectively influence happiness.

---

## 💡 Key Takeaways

* Happiness is influenced by a combination of **economic and social factors**
* Policies focusing only on GDP growth may not maximize well-being
* Improving healthcare and social support systems can significantly increase happiness levels
